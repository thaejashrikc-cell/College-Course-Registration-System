How adding works

A new node is made with malloc. If the list is empty, head points to it. Otherwise the program walks to the tail and links it there.

How dropping works

The program finds the matching code, links the previous node past it (or moves head forward), then calls free.

Speed and space

Search and tail-append take O(N). Extra space is O(1) beyond the nodes. Adding a tail pointer would make inserts O(1).
